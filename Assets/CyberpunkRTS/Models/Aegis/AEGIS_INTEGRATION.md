# Aegis Corp integration

Everything Aegis is generated by **Tools > GD5 > Build Aegis Faction** (`Assets/Scripts/Editor/AegisBuilder.cs` + `AegisBuilderExtras.cs`).
Re-run it after changing the tables in those files or after re-exporting the Aegis FBX files. It rebuilds materials, import
settings, prefabs, data, research, AI profiles, construction kit, FX, neutral pieces and props. Then run
**Tools > GD5 > Build Network Prefabs** so the Photon variants match.

| What | Path |
|---|---|

## Faction support

- `FactionId { Hive, Aegis }` on `Faction`, `UnitData.faction`, `BuildingData.faction`, `ResearchData.faction` (old assets default to Hive).
- `Faction.Of(team)`: online reads `RoomState.Factions[slot]` (synced, host/bot changeable), offline reads `Skirmish.PlayerFaction` /
  `Skirmish.Opponent.faction` (missions and tutorial are always Hive). Saved in `SaveData.playerFaction` and in each saved opponent.
- `Faction.Twin` pairs map Hive content to Aegis content (AI build orders, unit picks, tech requirements).
- Build menu = the player's faction's buildings, filtered by `BuildingData.faction`. Each factory/lab only lists its own faction's units/research.
- Starting base: `Faction.hq / factory / harvester` (Hive: Core Nexus, Assembly Hive, Data Harvester; Aegis: Command Spire, Barracks Bay, Collector),
  used by `MatchManager` offline (skirmish, AI) and online (players and lobby bots).

Every Hive unit and building now has its own Aegis twin, so Hive AI build orders, unit weights and research filters map one-to-one.

Aegis FX replacing the Hive ones (`AegisBuilder.FxSwap`, applied to every Aegis unit in `Visuals()`, sized to the Hive original by `Match()`):
`Bolt_Chain` -> `Arc_Aegis` (FX_AegisArc), `Shock_Thin/Soft/Pulse` -> `Impact_Aegis_Thin/Soft/Pulse` (FX_AegisImpact), `Flash_Heavy` -> `Punch_Aegis`
(FX_AegisPunch), `FX_Flame` -> `Flame_Aegis` (FX_AegisFlame, 2.2 x 2.2 x 6), `Scorch_*` -> `Scorch_Aegis_*` (FX_AegisScorch, each decal re-centred),
`Flash_Rifle` -> `Flash_Aegis`, `P_SMGTracer` -> `P_AegisTracer`. Wrecks added for Collector, Gunship, Interceptor, Skylift, Carrier and the Arc Turret.
`Fx` has `flicker` (emission dips, off with Reduce Flashing), `spin` (around world up) and `faceCamera`; `AegisBuilder.TuneFx()` sets them after the FX are built (arc crackle + random roll, rotating shock/stasis fields, punch star that faces the camera and lands on the Breaker's target).

Every combat unit has its own controller (Idle/Walk/Attack/Death, plus Deploy/Undeploy for the Bastion) with the same parameters as the Hive
`UnitLocomotion` controller (`Speed`, `Attack`) plus `Die`. Units with a wreck model use `UnitDeath.AnimateThenWreck` (Death 1-40, then
`Wreck_Aegis_<Name>`); the rest break apart like Hive units. Stats: Hive counterpart, then HP x1.15, cost x1.05, speed x0.9, then the
per-unit `Tuning` table in AegisBuilderExtras.cs (see AegisBalance.md).
Portraits: `UnitData.portrait` (`UI/Portraits/Aegis|Hive/portrait_<Name>.png`) is shown on the selected-unit card, falling back to the icon.

Buildings with `_Upgrade_Mk2/Mk3` groups have `BuildingUpgrade` + `UpgradeEffects` (templates keep their Hive upgrade effects; the others get
"+25% health" per level). `DamageFx` shows every `*_Damage` / `*_Damage_*` group below 50% health, hides it again when repaired above 50%, and
emits smoke at `*_SmokePoint*` and `AegisDmg_Spark` (from `FX_AegisDamage`) at `*_SparkPoint*`.
Team colour: renderers using `Aegis_TeamColor` get a shared per-colour tinted material from `TeamLook` (one material per colour, not per unit).

Construction: Aegis buildings use the Aegis kit in `ConstructionSite` (pad, scaffold growing to the building height, scan frame, welders;
Command Spire, Airfield, Refinery, Barracks Bay, Motor Pool, Drone Bay, Orbital Lance and Tech Center use the large pad/scaffold plus a looping crane).

## Research

17 Aegis research nodes (`AG_*`) mirror the Hive tree: same tiers, costs, requirements and effects, with unit/building filters swapped to the
Aegis counterparts. Hive-only flavour names were renamed (Suppression Protocols, Field Command Uplink, Orbital Uplink, Hardened Drill Heads).

## AI

`AIPlayer` loads `AI/Aegis_<level>` when its team is Aegis (generated with `AIPlayer.SwapProfile`: Hive build order and unit weights mapped to
Aegis, Motor Pool inserted, every Aegis unit gets a weight). It manages power with Fusion Reactors, harvests with Collectors, uses the Aegis roster
and fires the Orbital Lance through the existing superweapon logic.

## Neutral pieces and props

`Assets/Prefabs/Aegis/Neutral/Neutral_Corp_*` are built on the DerelictOutpost prefab (OutpostCapture + Outpost) with a **CorpSite** component:
CapturePoint (capture only), RepairBay (heals the owner's vehicles at `NRB_RepairPoint`), DataVault (+30 credits every 5 s to the owner),
Outpost (70 m sight for the owner). Idle 1-60 loops; `Aegis_TeamColor` banners are grey when neutral and the owner's colour when captured.
`MapBuilder.BuildCorp` places them on every map (symmetric per base) inside an Aegis plaza of `Prop_Aegis_*` props; the AI captures
and garrisons them (`AIPlayer.Outposts.cs`).

## Stubbed / known gaps

- ExtractionRig is a passive income building like the Hive siphon; Collectors do not dock at `ER_DockPoint`.
- Damage smoke and fire are the existing particle prefabs; only the sparks use the `FX_AegisDamage` meshes.
- Medic heal and Technician repair beams are the existing line beams (Aegis colours); `ABeam_Heal` and the `ARep_Arc` mesh are not used.
- Team colour uses shared tinted materials, not MaterialPropertyBlocks, because hit flashes already drive `_Color` through property blocks.
- Pulse Gate opens for friendly units near it, but pathfinding does not route through a closed gate.
